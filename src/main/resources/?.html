Game: Fast Typing

Goal: type as many correct words as possible in the shortest time.

Basic Rules

  • A word (or phrase) is displayed on the screen.
  • The player must type it exactly and press the Enter key or the verify button.
  • Each correct word adds score; every 5 correct words you level up.
  • There is a 30-second timer. The winner is the one who completes all levels before time runs out.

User Interface Elements

  1. Area where the word to type appears.
  2. Input field where the player types.
  3. Timer and score counter.
  4. Validate button.
